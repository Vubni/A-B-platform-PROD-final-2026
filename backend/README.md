# Backend

Этот каталог содержит backend-сервис LOTTY A/B Platform — монолит на `aiohttp` и PostgreSQL.

## Что здесь есть

- **Точка входа**: `server.py`
- **API и логика**:
  - HTTP-ручки — в `api/`
  - доменная логика — в `functions/`
  - работа с БД — в `database/`

## Где читать подробности

- **Главный `README` проекта** — запуск через Docker/без Docker, API, сценарии, архитектура: `../README.md`
- **Backend Runbook** — формат логов, нагрузка, триггеры БД, инженерная дисциплина: `Runbook.md`
- **Архитектура и соответствие критериям**:
  - C4-диаграммы: `docs/c4-diagrams.md`
  - матрица трассируемости: `docs/compliance-matrix.md`
  - demo-сценарии и гайд для проверяющего: `docs/demo-scenarios.md`, `docs/reviewer-test-guide.md`

Если нужна любая детальная информация (переменные окружения, жизненный цикл эксперимента, роли, ограничения и т.п.) — см. **корневой `README.md`** и файлы из раздела выше.
